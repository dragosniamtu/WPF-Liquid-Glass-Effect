# Third-Party Notices

This repository contains a WPF sample inspired by an internal XAMLTemplates.Net experiment and by publicly available writing about Liquid Glass-style shader effects.

## Medium Article Inspiration

The shader concept in this sample is inspired by:

- AmirHossein Aghajari, "Liquid Glass: iOS Effect Explanation", Medium, November 24, 2025.
- URL: https://medium.com/@aghajari/liquid-glass-ios-effect-explanation-dabadd6414ae

The implementation in this repository is written for WPF and Windows composition. It does not copy the article text into the source code.

## XAMLTemplates.Net Inspiration

The window style is adapted from the `GlassyWindowStyle` concept in:

- `XAMLTemplates.Net.WPF.Themes.Glass;component/Themes/Generic.xaml`
- specifically the merged `Themes/WindowStyle.xaml` resource dictionary.

The code here is packaged as a standalone public sample for the related blog article.
